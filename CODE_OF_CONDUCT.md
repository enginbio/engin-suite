# Code of Conduct

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct. The full text is maintained at that link and applies here in its entirety.

Contributor Covenant is published under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

## Scope

It applies in all project spaces — the repository, issues, pull requests, discussions — and when someone is representing the project publicly.

## Reporting

Report conduct issues to **conduct@engin.bio**. Reports go to the maintainer.

Two things worth being upfront about while this is a one-person project: there is no separate committee, and reporting a problem involving the maintainer means reporting it to the maintainer. That is a real limitation. Anyone uncomfortable with it should say so publicly in an issue, or contact one of the projects Engin depends on — several have conduct bodies that will hear concerns about ecosystem participants. This changes when there is more than one maintainer, and is one of several reasons that is a goal.

Reports are handled confidentially and acted on as promptly as circumstances allow.
