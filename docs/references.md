copy was used; `accessed` records when it was last read.

- **`2019-tibshirani-covariate-shift`** (accessed 2026-08-13) — NeurIPS proceedings are open-access without DOIs. arXiv is the canonical stable pointer.
- **`2021-angelopoulos-gentle-intro`** (accessed 2026-08-13) — A tutorial that circulates as a preprint; no journal version. Cited for exposition of the marginal-versus-conditional distinction, not for a result.
- **`2023-scientific-python-spec-9`** (accessed 2026-08-15) — A living community specification with no DOI and no versioned archive. The claim is about the structure this project's governance document follows, and the SPEC page is the only statement of it. Re-read on the quarterly liveness sweep rather than trusted to stay put.
- **`2024-responsible-biodesign-statement`** (accessed 2026-08-13) — A community statement published on its own site, with a signatory list still open. No DOI exists, and the signatory count is a moving figure -- which is itself why BIOSECURITY.md now dates the number it quotes.
- **`2026-benchling-allotropy`** (accessed 2026-08-16) — The claims are about what this library parses and what ASM can represent, and the repository is the reference for both. Re-counted from the GitHub API on 2026-08-16, correcting the 2026-08-14 reading of "~60 parser packages, none for a bioreactor or fermentor": **54** parser packages, and the sharper statement is about the *target model* rather than the parser list. The 26 shipped ASM schema families cover every analyzer that sits around a bioreactor -- metabolite-analyzer, solution-analyzer, bga, ph, cell-counting, plate-reader -- and include **nothing for a cultivation time series**. Two parsers are genuinely bioprocess-adjacent (NovaBio Flex2, Roche Cedex BioHT), so "none for a bioreactor" was true of controllers and misleading about analyzers. Architecture, also read from the repository: one hand-written package per instrument (``{vendor}_parser.py``, ``{vendor}_structure.py``), not a declarative grammar. That is what ADR 0009 cites it for.
- **`2026-cf-xarray-units`** (accessed 2026-08-11) — Library documentation, as above. The evaluation that rejected cf_xarray was run against the library itself; this is the reference for what it claims.
- **`2026-frictionless-detector`** (accessed 2026-08-11) — Library documentation. The claim is about what this software does, and the documentation is where it says so; there is no paper to cite instead.
- **`2026-jubiotech-detl`** (accessed 2026-08-14) — The claims are about what this repository contains -- an AGPL-3.0 licence and six real DASGIP/DASware exports committed as test fixtures -- and the repository is the reference for that. No release is published. Metadata read from the GitHub API on the accessed date; the fixture measured was tests/testfiles/v4_20180726.Control.csv.
- **`2026-numfocus-fiscal-sponsorship`** (accessed 2026-08-11) — An organisation's own statement of its requirements. It exists only as a web page and can change without notice, which is exactly why `accessed` is recorded and D25 names re-checking as a trigger.
- **`2026-pymcdm-methods`** (accessed 2026-08-13) — The claim is about what this library's API accepts, and the installed package is the reference for that. Evaluated at 1.4.0; the version is recorded because the answer can change.
- **`2026-scikit-criteria`** (accessed 2026-08-13) — As above -- a claim about an API, referenced to the package that defines it. Evaluated at 0.10.
